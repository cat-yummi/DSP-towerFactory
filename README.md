# 塔厂 (Tower Factory)

## 功能

让运输塔也能生产物资。

**塔厂条件：**
- 第一格放一种生产建筑（制造台、熔炉、化工厂、矩阵研究站等），这一格不能设置为需求或供应
- 第二格放该建筑的产品
- 后续格子按配方顺序放入原料

**采矿：**
- 第一格放采矿机，第二格放本行星有的矿物，生产该矿物（每座每分钟 30 个 × 采矿速度科技加成）
- 第一格放大型采矿机，以 3 倍速度生产第二格起的全部矿物（都必须是本行星有的矿物）
- 不消耗行星矿藏

**临界光子：**
- 第一格放射线接收站，第二格放临界光子
- 以射线接收站（满预热、无透镜）的速度制造光子，消耗戴森球的多余能量；能量不够就不产

**重氢：**
- 第一格放分馏塔，第二格放重氢，第三格放氢
- 每座分馏塔每半秒把 0.1 个氢转换为重氢

**伪配方（多步生产合并为一步，中间步骤计入生产统计）：**
- 石油精炼厂：4 原油 + 2 高能石墨 → 3 能量矩阵
- 石油精炼厂：1 精炼油 → 1 氢 + 1 高能石墨（第二格放哪个就收哪个）
- 石油精炼厂：2 原油 + 1 煤矿 → 3 精炼油
- 制造台：钛晶石 / 光栅石 + 可燃冰 + 氢 → 卡西米尔晶体

**副产物：** 只收第二格的产品，副产物丢弃，但计入生产统计。

**自动填原料：** 设好第一格（仓储）和第二格、后面留空，点运输塔窗口右上角的"塔厂：填原料"按钮，按配方填入原料（设为需求），伪配方优先。

满足条件并保持 1 秒后，这座塔成为"塔厂"：第一格有几座建筑，就以几倍的速度生产。

## 安装

使用 r2modman 或 Thunderstore Mod Manager 安装。

## 注意事项

- 忽略增产剂效果
- 不支持多人游戏（未测试）
